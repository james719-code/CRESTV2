# Frontend

This directory is reserved for the CREST web frontend. No frontend application or build tooling has been added yet.

The Android application lives in [`../android/`](../android/) and shared documentation lives in [`../docs/`](../docs/).

Use the shared [CREST branding kit](../branding/README.md) when implementing the web frontend. It defines Inter typography, theme colors, components, and vocabulary, with CSS generated from the same token source as Android.
