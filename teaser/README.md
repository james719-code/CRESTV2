# CREST V2 teaser

A 16-second mystery teaser. A handset turns out of darkness, briefly illuminating
the actual native Android app before the CREST V2 reveal. The complete screen
capture is fitted inside the device without cropping. No features are explained.
Native screens were captured from the Pixel emulator using production Compose
components with fictional offline records.

## Deliverables

- `out/CREST-V2-Cinematic.mp4`: 1920 × 1080, 30 fps, H.264, AAC stereo.
- `out/CREST-V2-Cinematic-Vertical.mp4`: 1080 × 1920, 30 fps, individually composed for vertical viewing.
- `out/CREST-V2-Cinematic-poster.png` and vertical equivalent.
- Editable React compositions in `src/MysteryTeaser.tsx`.

## Edit and preview

```powershell
cd teaser
npm ci
npm run studio
```

## Capture the real Android app

Start the Pixel emulator with the current debug APK installed. The existing debug
activity must be available; it is excluded from release builds. This workflow
does not sign into a school account or change school records.

```powershell
$env:ADB_PATH = 'C:\Users\James\AppData\Local\Android\Sdk\platform-tools\adb.exe'
npm run assets
npm run capture
npm run soundtrack
```

Raw Android captures and their provenance manifest are saved in
`../artifacts/teaser-emulator/` and copied into `public/screens/` for rendering.
The capture script uses `adb exec-out screencap -p`, preserving original PNG bytes.
If multiple devices are connected, select the intended emulator with the standard
`ANDROID_SERIAL` environment variable before capturing.

## Render

```powershell
npm run typecheck
npm run stills
npm run render:all
npm run verify
```

The renderer uses installed Google Chrome on Windows. Override `CHROME_PATH` if
needed. Rendering is entirely local. `npm run render` exports widescreen;
`npm run render:vertical` exports the vertical version.

Verification checks exact frame count, dimensions, duration, stereo audio, a full
decode of both MP4s, and byte equality of all used screens with the raw emulator
captures. It saves `out/verification.json` with output and capture SHA-256 hashes.

## Timing and assets

| Time | Scene |
| --- | --- |
| 0–3.65 s | A sliver of light. “Something’s changing.” |
| 3.55–7.18 s | A phone turns into the light, briefly revealing the native app |
| 7.12–9.2 s | “Look closer.” |
| 9.2–10.6 s | A large outlined 2 emerges |
| 10.6–11.1 s | Black and silence |
| 11.1–16 s | CREST V2. Coming soon. |

All motion is frame-based. Both compositions are exactly 480 frames at 30 fps.
Minimal text, a brief product reveal, and a deliberate pause preserve the surprise.

The supplied CREST logo is preserved. Inter is bundled with its OFL license in
`public/fonts/LICENSE.txt`. The instrumental score is original deterministic
synthesis, generated by `scripts/mystery-soundtrack.mjs`; it uses no external recordings
or music samples. The teaser makes no claim about a release date or push delivery.
